# Análisis de anuncios de vehículos

Aplicación web creada con Python, Streamlit, Pandas y Plotly
para explorar datos de anuncios de vehículos usados.

## Funcionalidades

- Vista previa del conjunto de datos.
- Histograma de la lectura del odómetro.
- Gráfico de dispersión entre odómetro y precio.
- Casillas para mostrar u ocultar los gráficos.

## Análisis exploratorio

El notebook notebooks/EDA.ipynb contiene la revisión inicial
de los datos, la identificación de valores faltantes y las
visualizaciones.

## Ejecutar la aplicación localmente

Instalar las dependencias:

    python -m pip install -r requirements.txt

Iniciar la aplicación:

    python -m streamlit run app.py
